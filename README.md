# 🚂 PI Planner — SAFe® 6.0 Program Increment & Dependency Matrix

> **An interactive Scaled Agile Framework (SAFe® 6.0) Program Increment planning platform with dynamic cross-squad red dependency strings, ROAM risk governance, and a built-in Scrum Master interview cheat sheet.** Built for enterprise Agile Release Trains (ARTs), Scrum Masters, and Delivery Leads.

Developed by **Balaji Palani** (Senior Scrum Master / Technical Agile Delivery Lead, CSM®, SAFe® 6 SSM).  
**Live Cloud URL:** [https://piplanner.onrender.com](https://piplanner.onrender.com)

---

## 🌟 Key Capabilities

- 🔗 **Interactive Program Board with Red Dependency Strings:** Visualizes cross-squad blockers using dynamic curved Bézier strings between team deliverables (e.g., Mobile Checkout blocked by Payments API).
- 🛡️ **Interactive ROAM Risk Matrix:** 4-column governance board (Resolved, Owned, Accepted, Mitigated) with one-click risk movement and impact tracking.
- 🎯 **Committed vs. Uncommitted PI Objectives:** Teaches and demonstrates the essential SAFe distinction to protect delivery predictability without sacrificing high-value buffer scope.
- 🖐️ **All-Hands Confidence Vote (Fist of Five):** Interactive 1-to-5 voting gauge calculating overall ART plan feasibility with celebration triggers.
- 🎓 **Built-in SAFe® 6.0 Interview Cheat Sheet:** Instant slide-out drawer defining all 8 core SAFe concepts (ART, PI, PI Planning, IP Sprint, Dependencies, ROAM, SoS, Fist of Five) with **exact "How to say it in an interview" word-for-word scripts**.
- 📋 **Enterprise Jira CSV & Confluence Export:** 1-click export generating RFC 4180 Jira-ready CSV files and formatted Markdown summary tables.
- 🎲 **Recruiter 1-Click Interactive Sandbox:** Test the critical path, simulate scheduling conflicts, and trigger confidence votes in seconds.

## 🛠️ Tech Stack & Zero-Cost Architecture

- **Frontend:** React 18, Vite 5, Tailwind CSS 3, Lucide React, Canvas Confetti.
- **Audio:** Native Web Audio API procedural synthesizer (zero audio files downloaded).
- **Backend / Deployment:** Node.js static server, Render `$0.00` free-tier cloud blueprint (`render.yaml`).

## 🚀 Quickstart

```bash
# Install dependencies
npm install

# Start production server
npm start

# Or run Vite dev server
npm run dev

```
